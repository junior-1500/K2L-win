# K2L-WIN v2

Application de pronostics sportifs utilisant les données de l'API Football de Sportmonks.

## Installation

1. Installer Node.js.
2. Ouvrir un terminal dans le dossier du projet.
3. Exécuter :

npm install

4. Créer un fichier `.env`.
5. Ajouter le token Sportmonks dans `.env`.
6. Lancer le serveur :

npm start

7. Ouvrir :

http://localhost:3000

## Sécurité

Ne jamais publier le vrai token Sportmonks sur GitHub.

Le fichier `.env` est ignoré par Git.
